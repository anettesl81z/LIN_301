Sets

  1. Unique words
unique_words = set(words)
print(len(unique_words))
  1. Type to token ratio
ttr_ratio = len(unique_words) / len(words)
print(ttr_ratio)
  1. The lines analyzed during class had high ratios because they were shorter and had less repetition of words. The Odyssey is a whole book, so the repetition is greater, and it results in a lower type-token ratio. I think that this happens because function words, like conjuntions and prepositions, will repeat more as the text gets longer.

Part 3 - Reflection

The thing that surprised me about working with a full text was the type-token ratio because of how much it differed compared to the lists we analyzed in class. Slicing the full text to find the actual lines of text that contained the actual poem. I don’t think that leaving the Gutenberg project information in the text significantly affected the type-token ratio because it was a small part of the text, and it was only at the beginning. For part 2 of the assignment, I think that the most natural structure to use was a dictionary because it uses key-value pairs, which is perfect for counting the number of times a character is mentioned in the text. The other options would not have been as effective because lists work better for ordered data, and sets are better for unique values, but they don’t have a way to store counts.
