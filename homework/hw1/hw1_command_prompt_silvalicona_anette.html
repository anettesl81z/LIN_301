Part 1 - Navigating and Managing Files

  1. Downloading The Adventures of Sherlock Holmes from Project Gutenberg:
curl -o "holmes.txt" https://www.gutenberg.org/cache/epub/1661/pg1661.txt
  1. Confirm the file downloaded and its size:
ls -l
  1. Creating nestled folders:
mkdir -p drafts/working/final
  1. Creating empty file:
touch log.txt
  1. Moving the empty file to folder:
mv log.txt drafts/working/final/
  1. Renaming the folder:
mv drafts/ notes/
  1. Creating throwaway folder and removing it:
mkdir scratch
rm -r scratch/
  1. Writing a script and running it
touch setup.sh

  • The script:

    mkdir backup_check
cd backup_check
curl -o holmes.txt https://www.gutenberg.org/cache/epub/1661/pg1661.txt
echo "Downloaded holmes.txt"

  • Running it:

    source setup.sh

  • Confirming it worked:

    ls

Answer: Both rmdir and rm -r are used to delete empty folders, but rmdir only works on completely empty folders while rm -r removes the folder and everything inside it without any safeguards, so it’s more dangerous. Either command would have worked for step 7 since the scratch folder was completely empty.

Part 2 - Counting and Searching

  1. Using wc, wc -l, and wc -w:
bash wc holmes.txt

12310 107558 607606 holmes.txt

wc -l holmes.txt

12310 holmes.txt

wc -w holmes.txt

107558 holmes.txt

  1. Searching for the word “Watson” in the text:
grep "Watson" holmes.txt
  • Piping:
grep "Watson" holmes.txt | wc -l
  1. Searching for the word “Holmes” in the text:
grep "Holmes" holmes.txt | wc -l
  • Holmes appears in 460 lines of the text while Watson appears in 81 lines of the text.
